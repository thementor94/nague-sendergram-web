# Portal Web y Landing Pages (`web/`)

Sitio web estático, landing pages informativas y consola web complementaria para la distribución y soporte de la Suite Bola r0ku.

---

## 1. Alcance y Propósito
El directorio `web/` provee recursos HTML5/CSS3/JS estáticos orientados a:
* Presentar las aplicaciones móviles a los usuarios finales y clientes potenciales (`index.html`).
* Ofrecer guías de usuario, manuales de uso y preguntas frecuentes (`ayuda.html`).
* Consola de administración ligera alternativa (`admin.html`).
* Componente embebible de asistencia y chat (`chat_widget.html`).

---

## 2. Estructura de Archivos

* [`index.html`](file:///home/r0ku/Descargas/Antigravity%20IDE/projects/apk%20bola/web/index.html): Página principal de aterrizaje y descarga de APKs.
* [`ayuda.html`](file:///home/r0ku/Descargas/Antigravity%20IDE/projects/apk%20bola/web/ayuda.html): Manuales interactivos y preguntas frecuentes de operación.
* [`admin.html`](file:///home/r0ku/Descargas/Antigravity%20IDE/projects/apk%20bola/web/admin.html): Panel administrativo web conectado a Supabase para visualización rápida.
* [`chat_widget.html`](file:///home/r0ku/Descargas/Antigravity%20IDE/projects/apk%20bola/web/chat_widget.html): Widget flotante para soporte por WhatsApp / mensajería.
* `assets/`: Recursos gráficos, iconos y estilos visuales compartidos.
